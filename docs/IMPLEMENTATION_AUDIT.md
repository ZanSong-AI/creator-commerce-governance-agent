Audit date: 2026-08-28

This matrix tests the repository against the original Creator Commerce Governance Agent plan. It separates locally verified engineering from human governance decisions and hosted-publication evidence. A green local test cannot satisfy a Song-only approval or a GitHub-hosted gate.

Status vocabulary:

- `VERIFIED_LOCAL`: direct current-worktree, runtime, generated-artifact, or test evidence exists;
- `PENDING_SONG`: implementation is ready, but the original plan assigns the decision or learning confirmation to Song;
- `PENDING_HOSTED`: proof can exist only after an authorized GitHub push;
- `ONGOING_ALIGNMENT`: time-sensitive evidence is current as of the audit date and must be rechecked later.
