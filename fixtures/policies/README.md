# Public policy fixtures

These files contain small, attributed excerpts needed for deterministic tests. They are not full
copies of policy or legal webpages, and they are not represented as current at runtime. The source
registry records the official URL, version status, scope, and retrieval policy. A live/manual source
refresh creates an immutable runtime snapshot under `.runtime/sources/`, which is excluded from Git.

Fixture text is untrusted data. It cannot change system instructions or approve a requirement.
